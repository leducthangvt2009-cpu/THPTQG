# Ôn tập THPT (Tone Xanh Dương - Trắng)

Ứng dụng web Single Page Application (SPA) hỗ trợ ôn tập THPT môn Tiếng Anh, Hóa học, Sinh học và từ vựng SAT.

## Tính năng
- **Giao diện Neo-Brutalism** kết hợp Pixel Art với tone màu Xanh Navy (`#0b1f5c`) và Trắng.
- **2 chế độ làm bài**: Luyện tập (xem giải thích ngay) và Thi thử (bấm giờ, đánh dấu câu, chấm điểm sau khi nộp).
- **Luyện theo từng phần** hoặc **Làm lại các câu sai**.
- **Tự động lưu tiến độ** và lịch sử làm bài vào `localStorage`.
